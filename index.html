Motion & Interaction

Animated Concepts

A demonstration of creative animations built with web technologies. Each example below is implemented using CSS @keyframes and transitions — no animation libraries or frameworks.

Animation 01

Floating Creative Elements

Decorative shapes drift gently up and down on a smooth keyframe loop. Each element uses a different duration and a negative delay so they move out of step with one another.

CSS keyframes · transform: translateY()

Design that moves.

Animation 02

Text Reveal Animation

A short creative message appears word by word. Each word slides and fades into place on a staggered delay, triggered when the section scrolls into view.

CSS keyframes · animation-delay · .reveal trigger

Animation 03

Rotating & Pulsing Element

A dashed ring spins at a steady rate while the core pulses in scale and opacity, showing two independent animations running together on the same element group.

CSS keyframes · rotate() · scale() · opacity
